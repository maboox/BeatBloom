# راهنمای فارسی BeatBloom Studio

BeatBloom یک استودیوی موسیقی سرگرم‌کننده و Local-first است که کاملاً داخل مرورگر اجرا می‌شود. حساب کاربری، سرور، تبلیغات یا ارسال اطلاعات ندارد.

## اجرای پیشنهادی

برای اینکه ضبط میکروفن بدون مشکل کار کند، برنامه را روی localhost اجرا کنید:

### ویندوز

روی `run-local.bat` دوبار کلیک کنید.

### macOS و Linux

```bash
chmod +x run-local.sh
./run-local.sh
```

سپس آدرس `http://localhost:8080` را باز کنید.

## امکانات مهم

- لوپ‌های ۸، ۱۶، ۲۴ و ۳۲ مرحله‌ای
- ۱۷ ردیف مستقل شامل درام، بیس، آکورد، لید، پلاک، گیتار و چهار ردیف سمپل
- پیانوی دو اکتاو؛ برای اکتاو بالاتر Shift را نگه دارید
- فرت‌بورد گیتار شش‌سیمه
- ضبط اجرای پیانو، گیتار، پدها و سمپل داخل سکوئنسر
- ضبط میکروفن و واردکردن فایل صوتی
- چهار اسلات سمپل با چهار ردیف مستقل Sample 1 تا Sample 4
- حالت One-shot یا Loop برای هر اسلات
- حالت Stack برای هم‌پوشانی صداها و Mono برای قطع صدای قبلی
- ذخیره دائمی سمپل‌ها داخل مرورگر
- تمپلیت‌های House، Lo-fi، Trap، Disco، Funk، Afro، Ambient، DnB، Arcade و Latin
- تکرار خودکار تمپلیت‌ها تا انتهای طول لوپ انتخاب‌شده
- خروجی WAV، ذخیره محلی پروژه و ورود/خروج JSON

## ضبط اجرای زنده

1. طول لوپ را انتخاب کنید.
2. دکمه قرمز Record را بزنید.
3. با پیانو، گیتار، پدها یا سمپل بنوازید.
4. اجرا به‌صورت خودکار داخل ردیف مربوط ثبت می‌شود.
5. برای پایان دوباره Record را بزنید.

## سمپل و صدای شخصی

1. یکی از اسلات‌های ۱ تا ۴ را انتخاب کنید.
2. روی Record microphone بزنید یا فایل صوتی وارد کنید.
3. حالت 1-shot یا Loop را انتخاب کنید.
4. با کلیک Play یا کلیدهای ۱ تا ۴ صدا را اجرا کنید.
5. هر اسلات همیشه به ردیف هم‌شماره خودش در سکوئنسر متصل است؛ Sample 1 تا Sample 4.

تمام صداها روی همان دستگاه و داخل IndexedDB مرورگر نگهداری می‌شوند.
