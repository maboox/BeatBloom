# Code of Conduct

We want BeatBloom to be a welcoming project for creators and contributors of every background and experience level.

Be respectful, constructive, and patient. Critique ideas and code rather than people. Harassment, discrimination, threats, doxxing, or deliberately disruptive behavior are not acceptable.

Project maintainers may edit or remove comments, issues, or contributions that violate these expectations and may temporarily or permanently restrict participation when necessary.
