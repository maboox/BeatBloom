# BeatBloom 4.0 — Your little corner of sound

A warmer, clearer local music studio with an orange interface and English/Persian support.

- Shared live/offline audio: WAV includes the actual instruments, samples, swing, gain and effects.
- Portable `.beatbloom` projects contain all four audio slots.
- Undo/redo, per-lane volume, independent recorded notes and explicit piano keyboard mode.
- Safer file validation, text-only filenames, limited microphone recordings and local-data deletion.
- Responsive controls, local Lucide icons, keyboard access and reduced-motion support.
- Reproducible builds and automated code, browser, accessibility and security checks.

Open the hosted studio, or serve the web archive on localhost/HTTPS. The source requires Node.js 24 LTS (minimum 22.13), `npm ci --ignore-scripts`, then `npm run dev`. Opening source files directly with `file://` is no longer supported.

Existing v1–3.1 JSON arrangements can be imported. Those old files do not include sample audio; export a new portable project after loading the correct local samples. Keep backups before clearing browser storage.

## فارسی

نسخهٔ ۴ با ظاهر نارنجی، رابط فارسی و انگلیسی، خروجی WAV هماهنگ با پخش زنده و فایل پروژهٔ همراه سمپل‌ها آماده است. بازگشت تغییرات، حجم مستقل سازها، حفظ نت اجرای زنده و کلیدهای پیانوی بدون تداخل اضافه شده‌اند. ورود فایل، ضبط میکروفن و حذف داده‌های محلی هم ایمن‌تر و روشن‌تر شده است.

نسخهٔ میزبانی‌شده را در مرورگر باز کن. برای اجرای سورس به Node.js و ساخت با Vite نیاز است. فایل‌های قدیمی پروژه پذیرفته می‌شوند، ولی صداهای آن‌ها همچنان باید در اسلات‌های مرورگر موجود باشند.
